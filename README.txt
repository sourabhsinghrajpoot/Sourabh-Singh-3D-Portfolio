SOURABH SINGH — PORTFOLIO

Open index.html in a modern browser to view the portfolio. The site is built with plain HTML, CSS, and JavaScript; it does not need a build step or package installation.

Included files
- index.html: portfolio content and page structure
- styles.css: responsive styling, motion, and 3D visual treatments
- script.js: reveal animations, pointer glow, and project-card tilt
- assets/portrait.png: supplied portrait
- assets/resume.pdf: supplied résumé, available from the download links

The site uses Google Fonts when an internet connection is available and falls back to system fonts when offline. The Zidio internship appears as requested; its dates and responsibilities were not provided, so the page leaves them unspecified.

To publish, upload the contents of this folder to any static web host.
